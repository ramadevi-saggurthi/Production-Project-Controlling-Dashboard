# Production Project Controlling Dashboard

## Project Overview
This project is a simulated manufacturing case study focused on production project controlling, budget monitoring and cost variance analysis.

## Project Objectives
- Monitor planned budgets against actual expenditure.
- Calculate cost variances across manufacturing projects.
- Identify projects with budget overruns.
- Support management decision-making through data reporting.

## Tools & Technologies
- Microsoft Excel – Data analysis and cost calculations
- Microsoft PowerPoint – Management reporting
- Microsoft Word – Project documentation
- GitHub – Project versioning and portfolio presentation

## Project Scope
The case study covers five hypothetical manufacturing projects with assigned budgets and actual costs.

## Key Performance Indicators
- Total planned budget
- Actual expenditure
- Cost variance
- Budget deviation percentage

## Expected Learning Outcomes
- Budget planning and monitoring
- Cost variance analysis
- Production project controlling
- Data visualization
- Management communication

## Project Deliverables
- Excel cost analysis workbook
- PowerPoint management presentation
- Word project report
